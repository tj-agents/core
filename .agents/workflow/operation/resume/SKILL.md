# Resume named work

Resolve the exact goal and native identity from the supplied pointer and the `agent:recover` inventory. For repository work, reconcile its checkout, branch and selected ledger with Git or provider evidence. For standalone work, verify the task directory and existing artifact without inventing a repository or ledger. Stored read-only rows are not live-process proof. Refuse ambiguous or observed-live takeover and reuse the existing owner.

Reconstruct missing recovery facts from evidence and preserve partial writes. A verified compact continuation containing goal, absolute working directory, state and next action needs targeted confirmation rather than a full corpus reread; repository work also confirms its branch through Git. Contradictions require targeted reconstruction. Preserve authority after reconstruction: planning-only work returns to `workflow:plan`, and already-authorized execution returns to `workflow:run`. Resolve a missing product choice rather than guessing among goals. Never create a second executor or goal.
